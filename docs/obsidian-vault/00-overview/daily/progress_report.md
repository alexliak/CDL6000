## 🛠️ Τεχνικές Λεπτομέρειες

### Βασικά Modules
1. **Preprocessor**: `src/core/preprocessor.py`
   - Βασική επεξεργασία νομικών εγγράφων
   - Εξαγωγή παραπομπών και χρονολογιών
   - Βελτιστοποίηση μνήμης με batch processing

2. **Classifier**: `src/core/classifier.py`
   - Πολλαπλοί αλγόριθμοι ταξινόμησης
   - Βελτιστοποίηση GPU για ταχύτερη εκπαίδευση
   - Αποθήκευση και φόρτωση μοντέλων

3. **Legal Extractor**: `src/ml/legal_extractor.py`
   - Εξαγωγή νομικών όρων και οντοτήτων
   - Αναγνώριση ειδικών νομικών δομών
   - Συνεργασία με τον preprocessor

4. **Vectorizer**: `src/ml/vectorizer.py`
   - Εξειδικευμένη διανυσματοποίηση νομικών κειμένων
   - Ενσωμάτωση νομικών χαρακτηριστικών
   - Βελτιστοποίηση με μείωση διαστάσεων

5. **Metrics**: `src/core/metrics.py`
   - Παρακολούθηση απόδοσης επεξεργασίας
   - Μέτρηση και αξιολόγηση ταξινόμησης
   - Οπτικοποίηση αποτελεσμάτων

### Αρχιτεκτονική Συστήματος

```
[Είσοδος: Νομικά Έγγραφα] → [Preprocessor] → [Legal Extractor]
                                     ↓
[Διανυσματοποίηση] ← [Vectorizer] ← [Εξαγωγή Χαρακτηριστικών]
                                     ↓
[Έξοδος: Κατηγορίες & Μετρικές] ← [Classifier]
```
