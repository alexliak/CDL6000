# Τεχνικές Προδιαγραφές CDL6000

## 1. Εισαγωγή

Το CDL6000 είναι ένα σύστημα αυτοματοποιημένης ταξινόμησης νομικών εγγράφων που χρησιμοποιεί τεχνικές μηχανικής μάθησης και επεξεργασίας φυσικής γλώσσας. Το παρόν έγγραφο περιγράφει τις τεχνικές προδιαγραφές και απαιτήσεις του συστήματος.

## 3. Αρχιτεκτονική Συστήματος

### 3.1 Επισκόπηση

Το σύστημα ακολουθεί μια αρθρωτή αρχιτεκτονική με διακριτά components:

```
[Document] → [Preprocessor] → [Feature Extractor] → [Vectorizer] → [Classifier] → [Category]
                    ↓                                                    ↓
            [Performance Monitoring] ←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←←
```

### 3.2 Components

#### 3.2.1 Preprocessor
- **Αρχεία**: `src/core/preprocessor.py`
- **Λειτουργία**: Προεπεξεργασία νομικών εγγράφων
- **Χαρακτηριστικά**: 
  - Καθαρισμός κειμένου
  - Εξαγωγή βασικών χαρακτηριστικών
  - Batch processing για βελτιστοποίηση μνήμης

#### 3.2.2 Legal Extractor
- **Αρχεία**: `src/ml/legal_extractor.py`
- **Λειτουργία**: Εξαγωγή νομικών όρων και οντοτήτων
- **Χαρακτηριστικά**:
  - Αναγνώριση παραπομπών
  - Εντοπισμός νομικών όρων
  - Εξαγωγή χρονολογιών

#### 3.2.3 Vectorizer
- **Αρχεία**: `src/ml/vectorizer.py`
- **Λειτουργία**: Μετατροπή κειμένου σε διανύσματα
- **Χαρακτηριστικά**:
  - TF-IDF για γενικά χαρακτηριστικά κειμένου
  - Ειδικά χαρακτηριστικά για νομικά κείμενα
  - Μείωση διαστάσεων για βελτιστοποίηση

#### 3.2.4 Classifier
- **Αρχεία**: `src/core/classifier.py`
- **Λειτουργία**: Ταξινόμηση εγγράφων σε κατηγορίες
- **Χαρακτηριστικά**:
  - Πολλαπλοί αλγόριθμοι (SVM, Naive Bayes, Random Forest)
  - Βελτιστοποίηση GPU
  - Αποθήκευση και φόρτωση μοντέλων

#### 3.2.5 Performance Monitoring
- **Αρχεία**: `src/core/metrics.py`
- **Λειτουργία**: Παρακολούθηση απόδοσης συστήματος
- **Χαρακτηριστικά**:
  - Μέτρηση χρόνου επεξεργασίας
  - Παρακολούθηση χρήσης μνήμης
  - Καταγραφή μετρικών ταξινόμησης
