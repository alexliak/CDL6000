# Obsidian Academic Workflow Guide

## Daily Workflow

### 1. Morning Routine
1. Open course hub (`00-academic-hub/index.md`)
2. Review daily objectives
3. Check upcoming deadlines
4. Update weekly log

### 2. Research Session
1. Create new research notes in relevant course folder
2. Link notes using `[[double brackets]]`
3. Tag notes appropriately (#research, #implementation, etc.)
4. Update reference tracking

### 3. Implementation Work
1. Document code changes in development logs
2. Link GitHub commits to daily notes
3. Update experiment results
4. Cross-reference with research notes

### 4. End of Day
1. Update weekly log
2. Track time spent on activities
3. Set objectives for next day
4. Push changes to backup

## Key Plugins to Install

1. Citations
- Use for managing academic references
- Link to Zotero

2. Dataview
- Create dynamic lists and tables
- Track progress across notes

3. Calendar
- Link notes to specific dates
- Track deadlines

4. Mind Map
- Visualize connections between notes
- Plan thesis structure

## Essential Links & Tags

### Tags Structure
```markdown
#assessment      - Assessment related content
#research        - Research materials
#implementation  - Code and development
#meeting         - Meeting notes
#deadline        - Important dates
#reference       - Citation and references
```

### Critical Links
- Link between weekly logs and research notes
- Link between assessments and supporting materials
- Cross-reference between courses where relevant

## Grade Optimization

### Weekly Review Process

3. Review assessment criteria
4. Update progress tracking

### Assessment Preparation
1. Create assessment checklist
2. Gather relevant research notes
